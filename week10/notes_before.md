# week09/tools.py 분석 노트

## 개요
- 영화진흥위원회(KOBIS) 오픈 API로 **일별 박스오피스** 정보를 가져오는 도구 모음입니다.
- 사용하는 라이브러리: `requests`
- API 키는 `secret.py`의 `API_KEY`에서 불러옵니다.
- 요청 주소(`BASE_URL`): `searchDailyBoxOfficeList.json` (일별 박스오피스 목록)

## 함수 목록

### `get_boxoffice_rank_1(date)`
지정한 날짜의 박스오피스 **1위 영화 제목**을 돌려줍니다.

| 항목 | 내용 |
|---|---|
| 입력 | `date` (문자열): 8자리 날짜. 예: `"20261013"` |
| 출력 | (문자열): 1위 영화 제목. 예: `"오디세이"` |

**동작 순서**
1. `key`(API 키)와 `targetDt`(날짜)를 요청 파라미터로 만듭니다.
2. `requests.get`으로 API를 호출합니다(제한 시간 10초).
3. JSON 응답에서 `boxOfficeResult` → `dailyBoxOfficeList`를 꺼냅니다.
4. 목록의 첫 번째 항목(1위)에서 `movieNm`(영화 제목)을 돌려줍니다.

## 참고 / 개선할 점
- JSON 응답을 매개변수 이름과 같은 `date` 변수에 다시 저장하고 있어서 읽기 헷갈립니다. `data` 같은 다른 이름을 쓰는 것이 좋습니다.
- 오류 처리가 없습니다. 날짜 형식이 틀렸거나 API 키가 잘못됐거나 결과 목록이 비어 있으면 `KeyError` 또는 `IndexError`가 납니다.
- 1위 영화만 가져올 수 있습니다. 순위를 인자로 받거나 전체 목록을 돌려주도록 확장할 수 있습니다.
